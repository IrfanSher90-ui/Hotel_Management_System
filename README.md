 Hotel Management System
A comprehensive and fully responsive web application designed to streamline hotel operations, from guest bookings to administrative oversight.

 Key Features
Role-Based Access Control: Distinct portals for Admin and Staff members.

Smart Booking System: Interactive dashboard to manage and track room reservations.

User Authentication: Secure Login and Signup functionality for all users.

Admin Power-Hub: Dedicated dashboard for monitoring staff activities and generating reports.

Automated Notifications: Real-time alerts for new bookings and system updates.

Modern UI/UX: Fully responsive design that works perfectly on mobile, tablet, and desktop.

 Payment Integration (Demo)
The system includes an integrated Payment Gateway UI.

Note: Currently, the payment module is in Demo Mode for architectural demonstration and does not process real-time transactions.

 Tech Stack & Implementation
Frontend: HTML5, CSS3 (Responsive Design), JavaScript.

Backend & Auth: Functional authentication and booking logic.

Status: The core modules (Auth, Booking, Admin Dash) are fully functional. Some secondary modules (Reports, Advanced Settings) are currently implemented as Frontend Prototypes to showcase the intended system flow.

 How to Run
Clone the repository.

Open index.html (or your main entry file) in any modern browser.

Use the Admin/Staff credentials to explore the dashboards.
